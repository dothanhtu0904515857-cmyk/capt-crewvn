Organise checklists by phase (BEFORE / DURING / AFTER) or by department (MASTER / BRIDGE / DECK / ENGINE /
DOCUMENTATION). For equipment inspection use: IDENTIFICATION → DOCUMENT CHECK → VISUAL/STATIC INSPECTION →
OPERATIONAL TEST → PERFORMANCE READINGS → ALARM/INTERLOCK → SPARES → DEFECTS → EVIDENCE → ACTION → SIGN-OFF.
