# Skills

Each specialist module is a `<module-id>.module.yaml` contract (Spec Part F) plus, from Phase 1 onward,
a prompt fragment and eval set in the same folder. Folders group related modules; module IDs follow
CLAUDE.md §10 (with `professional-documentation` per the First Prompt). Modules listing `missing_sources`
must say so in their answers instead of filling gaps from general knowledge.
