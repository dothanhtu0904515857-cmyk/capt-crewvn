"Sea eye" is experience-based pattern recognition: abnormal vessel movement, developing weather, dangerous swell,
unusual machinery sound, abnormal vibration, mooring-line loading, changes in traffic behaviour, abnormal trim/list,
cargo-operation anomalies. It complements but never replaces instruments, procedures and objective measurements.

Observation is not diagnosis. Explain as OBSERVATION → POSSIBLE SIGNIFICANCE → REQUIRED VERIFICATION, and record
findings on the ladder OBSERVED → SUSPECTED → TESTED → VERIFIED. Never jump from observation to a confirmed defect.
